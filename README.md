## Overview
This project is a timer application designed for the Pomodoro technique. Users can set daily goals and track their progress with various features. The application includes a task list, music playback, goal tracking system, sound effects, motivational quotes, and the well-known "don't break the chain" system.

## Features
**Pomodoro Timer:** A timer for practicing the Pomodoro technique.

**Task List (ToDo List):** A list to add and organize your daily tasks.

**Music Integration:** Enjoy music by integrating your Spotify playlist.

**Task Tracking:** Track your daily goals and tasks.

**Sound Effects:** Audio feedback for Pomodoro sessions and other interactions.

**Quotes:** Display random or user-defined motivational quotes.

**Streak Tracking:** Monitor your habits and consistency with streak tracking.
